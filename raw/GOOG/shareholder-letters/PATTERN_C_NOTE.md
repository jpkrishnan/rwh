# GOOG Shareholder Letter Pattern

**Pattern**: C — No standalone annual shareholder letter

Alphabet does not publish a separate annual founder/CEO letter in the traditional sense.
Larry Page and Sergey Brin last published standalone annual letters around 2019.
Sundar Pichai's primary written communications are:
1. CEO/Founders' letter embedded in the Annual Report
2. DEF 14A proxy statement introductory letter
3. Quarterly earnings call remarks (transcribed on blog.google)
